## 第二模块：核心架构解释

Being-H0.7 的整体架构基于 **Mixture-of-Transformers (MoT)**，包含一个处理语言与视觉上下文的 **Understanding Expert** 和一个处理状态与动作生成的 **Action Expert**。模型在标准 VLA 的输入序列中插入了一组可学习的**隐式查询（latent queries）**，作为连接感知与动作的紧凑推理接口。

**输入序列构建**。给定语言指令 $x$、历史观测 $o_{-H:0}$、当前状态 $s$、待生成的动作块 $a_{0:T}$，以及 $K=16$ 个隐式查询 $Q$，序列被组织为：
$$S = [x;\, o_{-H:0};\, s;\, Q;\, a_{0:T}]$$
这些查询在 Transformer 逐层传播中与上下文交互，聚合任务相关信息，形成动作导向的隐式状态。

**双分支训练设计**。为了将未来信息注入隐式空间，同时保持推理路径的可部署性，作者设计了两个结构对齐的分支：
- **先验分支（Prior Branch）**：使用可学习的 $Q$ 作为隐式推理起点，仅依赖当前上下文，是推理时的唯一路径。
- **后验分支（Posterior Branch）**：训练专用，将 $Q$ 替换为未来观测 $\tilde{o}_{0:T}$ 经冻结 ViT 与 Perceiver Resampler 压缩后的嵌入 $z^{\mathrm{post}} \in \mathbb{R}^{K \times d}$。

两个分支共享相同的上下文编码，通过 **dual-branch attention mask** 打包进单一序列完成一次前向传播：共享上下文对两分支可见，但先验与后验的 token 互不交互，确保对齐仅发生在指定的隐式位置。

**训练目标**。总损失包含三项：
1. **Flow Matching 动作损失** $\mathcal{L}_{\mathrm{FM}}$：对两个分支分别计算速度场预测误差。
2. **隐式对齐损失** $\mathcal{L}_{\mathrm{align}}$：对最后 $L=9$ 层 Transformer 中对应隐式位置的隐藏状态 $h_\ell^{\mathrm{prior}}$ 与 $h_\ell^{\mathrm{post}}$ 施加逐点 Frobenius 范数对齐。
3. **反坍缩正则** $\mathcal{L}_{\mathrm{reg}}$：包含模长正则 $\mathcal{R}_{\mathrm{norm}}$（防止 $\|h\|_2$ 低于阈值 $\tau$）与谱多样性正则 $\mathcal{R}_{\mathrm{rank}}$（通过最小化负谱熵防止方向坍缩）。

最终损失为：
$$\mathcal{L} = \mathcal{L}_{\mathrm{FM}} + w_{\mathrm{align}} \mathcal{L}_{\mathrm{align}} + \mathcal{L}_{\mathrm{reg}}, \quad w_{\mathrm{align}}=10^{-3},\; w_{\mathrm{norm}}=w_{\mathrm{rank}}=10^{-4}$$

**推理与部署**。推理时完全移除后验分支，模型仅运行先验分支，不生成任何未来帧。配合 **Universal Async Chunking (UAC)** 异步分块机制，系统级延迟控制在 **3–4 ms/step**，与标准 VLA 相当。

**实验流程**。模型首先在混合人与机器人操作数据的 **UniHand 2.0** 统一格式上进行大规模预训练，随后在六个仿真基准（LIBERO、RoboCasa-50、GR1、LIBERO-plus、RoboTwin 2.0、CALVIN）和三类真实平台（PND Adam-U、Unitree G1、Franka FR3）的 12 项组合式任务上进行微调与评估。

import torch
import torch.nn as nn

class BeingH07(nn.Module):
    def __init__(self, K=16, d=768, L_align=9):
        super().__init__()
        self.understanding_expert = MoTTransformer()   # Understanding Expert
        self.action_expert = MoTTransformer()          # Action Expert
        self.latent_queries = nn.Parameter(torch.randn(K, d))  # 先验隐式查询
        self.future_encoder = PerceiverResampler()     # 冻结ViT + Resampler
        self.flow_head = FlowMatchingHead()
        self.K = K
        self.L_align = L_align
        self.w_align = 1e-3
        self.w_reg = 1e-4
        self.tau = 0.5  # 模长阈值

    def forward(self, x, o_hist, s, a_gt, o_future=None):
        # 编码共享上下文
        c = encode_context(x, o_hist, s)  # [B, N_ctx, d]
        
        # 先验分支：可学习查询
        q_prior = self.latent_queries.unsqueeze(0).expand(B, -1, -1)
        seq_prior = build_mot_sequence(c, q_prior, a_gt, branch='prior')
        
        if self.training and o_future is not None:
            # 后验分支：未来观测嵌入
            with torch.no_grad():
                z_post = self.future_encoder(o_future)  # [B, K, d]
            seq_post = build_mot_sequence(c, z_post, a_gt, branch='posterior')
            
            # 打包为单一序列，应用 dual-branch attention mask
            seq_packed, attn_mask, pos_ids = pack_dual_branch(seq_prior, seq_post)
            hidden_packed = self.understanding_expert(seq_packed, attn_mask, pos_ids)
            
            # 解包两分支的隐藏状态
            h_prior, h_post = unpack_latent_hidden(hidden_packed, self.L_align)
            
            # 1) Flow Matching 损失（两分支）
            a_t, u_t = sample_flow_path(a_gt)
            v_prior = self.flow_head(a_t, h_prior)
            v_post = self.flow_head(a_t, h_post)
            loss_fm = ((v_prior - u_t)**2).mean() + ((v_post - u_t)**2).mean()
            
            # 2) 隐式空间对齐（最后 L_align 层）
            loss_align = 0.0
            for l in range(self.L_align):
                loss_align += ((h_prior[l] - h_post[l])**2).mean()
            loss_align = loss_align / self.L_align
            
            # 3) 反坍缩正则
            loss_reg = 0.0
            for h in [h_prior, h_post]:
                # 模长正则
                norm = h.norm(dim=-1)
                loss_reg += self.w_reg * (torch.relu(self.tau - norm)**2).mean()
                # 谱多样性正则（负谱熵）
                loss_reg += self.w_reg * spectral_entropy(h)
            
            loss = loss_fm + self.w_align * loss_align + loss_reg
            return loss
        else:
            # 推理：仅先验分支，无未来帧生成
            hidden = self.understanding_expert(seq_prior)
            action = self.flow_head.decode(hidden)
            return action

## 第二模块：核心架构解释

本综述的核心“架构”是其**概念分类框架与组织逻辑**，而非单一模型。作者首先建立一个概率统一视角，随后从架构耦合度和功能角色两个维度对文献进行正交拆解。

### 1. 概率统一视角
作者将策略、世界模型与逆动力学模型统一为同一联合分布的不同查询方式：
- **联合分布**：$p(o_{t+1:t+k}, a_{t+1:t+k} \mid o_t, l)$
- **策略模型**：对观测积分，$p(a \mid o, l) = \int p(o, a \mid o_t, l)\, do$
- **被动世界模型**：对动作积分，$p(o \mid o_t, l) = \int p(o, a \mid o_t, l)\, da$
- **可控世界模型**：条件于动作，$p(o \mid o_t, a)$
- **逆动力学模型**：条件于未来观测，$p(a \mid o_{t:t+k})$

这一透镜表明：世界模型与策略并非天然分离的模块，而是同一预测-控制结构的不同因子化。

### 2. 策略耦合的五大架构范式（表 1）
按**预测生成与动作生产的交互方式**分类：

- **IDM-style（逆动力学式）**：解耦的“先预测未来，再解码动作”。世界模型 $\mathcal{W}$ 生成未来观测 $\hat{\mathbf{o}}_{t+1:t+H}$ 或其隐式表征 $\hat{\mathbf{z}}$，再由独立策略头 $\pi$ 映射为动作。代表：UniPi、VPP、TC-IDM。优点是模块化、可解释；缺点是误差累积且预测未必动作一致。
- **Single-backbone（单骨干式）**：观测与动作 token 在统一生成骨干内联合建模，共享去噪/自回归过程。目标为 $\mathcal{L}_{\mathrm{unified}} = \mathbb{E}[\ell(\hat{y}, y)]$，其中 $\mathbf{x}=[z^{v};z^{a}]$。代表：UVA、UWA、Cosmos Policy。优点是可注入大规模视频预训练先验；缺点是推理开销大。
- **MoE/MoT（专家混合式）**：保留视频专家与动作专家的参数分离，通过共享注意力、交叉注意力或交错序列实现深度耦合。代表：Motus、LingBot-VA、DiT4DiT。兼顾模态特异性与信息交互。
- **Unified VLA（统一 VLA 式）**：在 MLLM 骨干内部内化未来预测（未来图像、结构化世界知识或子目标），而非外挂独立世界模型。代表：GR-1、WorldVLA、DreamVLA。
- **Latent-space WM（隐空间式）**：完全避免像素解码，在表示空间预测未来嵌入或条件。代表：FLARE、VLA-JEPA、WoG。计算高效，但损失了显式未来可视化。

### 3. 模拟器双角色框架（第 4 节）
世界模型作为模拟器被划分为两种互补功能：
- **RL 模拟器**：替代真实环境进行策略强化学习。优化目标 $J(\theta) = \mathbb{E}_{\hat{\tau}\sim(\pi_{\theta}, p_{\phi})}[\sum_{t} \gamma^t \hat{r}_t]$，演进路径从静态预训练模拟器（World-Env）到策略-世界模型协同进化（WoVR）。
- **评估器**：在决策时或离线阶段对候选动作/策略进行排名、验证与安全过滤。代表：GPC（在线候选排名）、WorldEval（离线策略评估）。

### 4. 视频世界模型四阶段演进（第 5 节）
- **Imagination-based**：作为想象引擎提供策略监督（Dreamitate、RoboDreamer）
- **Action-controllable**：强调帧级动作条件与因果对齐（IRASim、Ctrl-World）
- **Structure-aware**：引入掩码、几何、多视角等结构先验（TesserAct、RoboVIP）
- **Foundation-scale**：将大规模视频生成基础模型适配为可复用的交互式世界模型（Vid2World、Genie Envisioner、Cosmos Predict）

### 伪代码：通用世界模型策略推理框架

```python
def world_model_policy_inference(
    obs_t, 
    language_instruction,
    paradigm="single_backbone",  # "idm" | "single_backbone" | "moe" | "latent"
    world_model=None,
    policy_head=None,
    action_candidates=None
):
    """
    基于综述统一概率视角的通用推理框架。
    可实例化为表1中的不同架构范式。
    """
    condition = encode_multimodal(obs_t, language_instruction)
    
    if paradigm == "idm":
        # 解耦范式：显式未来生成 + 逆动力学解码
        future_obs = world_model.sample_future(condition, horizon=H)
        future_repr = feature_extractor(future_obs)  # 对应论文 Φ(·)
        action = policy_head.decode(obs_t, condition, future_repr)
        
    elif paradigm == "single_backbone":
        # 统一范式：联合去噪/生成未来表征与动作
        latent = world_model.init_joint_latent(video_tokens=obs_t, cond=condition)
        for step in range(world_model.num_denoising_steps):
            # 同时去噪视频 token 与动作 token
            latent = world_model.denoise_step(latent, condition, timestep=step)
        action = extract_action_tokens(latent)
        # 可选：显式未来输出用于规划或验证
        future_obs = extract_video_tokens(latent)
        
    elif paradigm == "moe":
        # MoE/MoT 范式：分离专家 + 层间交叉注意力耦合
        h_video = world_model.video_expert(condition)
        h_action = world_model.action_expert(condition)
        for layer in world_model.mixture_layers:
            h_video, h_action = layer.cross_attend(h_video, h_action)
        action = policy_head(h_action)
        
    elif paradigm == "latent":
        # 隐空间范式：无像素解码，直接预测未来嵌入
        future_embedding = world_model.predict_latent_target(obs_t, condition)
        action = policy_head(obs_t, condition, future_embedding)
    
    # 扩展：若用于评估/规划，对候选动作进行推出排名
    if action_candidates is not None:
        scores = [
            world_model.evaluate_rollout(obs_t, cand, condition) 
            for cand in action_candidates
        ]
        action = action_candidates[argmax(scores)]
        
    return action
```

当前视觉-语言-动作（VLA）模型虽能直接将多模态观测映射为动作，但稀疏的动作监督易导致捷径学习，缺乏对动力学、接触与任务进度的深层表征。近期世界动作模型（WAM）通过视频推演引入未来预测，然而像素级未来生成计算昂贵，且可能建模与动作无关的视觉细节，造成训练与推理的双重瓶颈。

实验覆盖六个仿真基准（LIBERO、RoboCasa、GR1、LIBERO-plus、RoboTwin 2.0、CALVIN）与三种真实机器人平台（PND Adam-U、Unitree G1、Franka FR3）的12项任务。仿真中，Being-H0.7取得SOTA或可比性能，如LIBERO平均99.2%、RoboCasa 62.1%、CALVIN 4.67/4.48。真实世界中，在动态场景、物理推理、运动推理、长程执行与泛化五个能力套件上均领先于π0.5、Fast-WAM等强基线；结合异步分块推理（UAC），系统延迟仅3–4 ms/步。

## 第二模块：核心架构解释

Being-H0.7 的整体架构基于 **Mixture-of-Transformers (MoT)**，包含一个处理语言与视觉上下文的 **Understanding Expert** 和一个处理状态与动作生成的 **Action Expert**。模型在标准 VLA 的输入序列中插入了一组可学习的**隐式查询（latent queries）**，作为连接感知与动作的紧凑推理接口。

**输入序列构建**。给定语言指令 $x$、历史观测 $o_{-H:0}$、当前状态 $s$、待生成的动作块 $a_{0:T}$，以及 $K=16$ 个隐式查询 $Q$，序列被组织为：
$$S = [x;\, o_{-H:0};\, s;\, Q;\, a_{0:T}]$$
这些查询在 Transformer 逐层传播中与上下文交互，聚合任务相关信息，形成动作导向的隐式状态。

**双分支训练设计**。为了将未来信息注入隐式空间，同时保持推理路径的可部署性，作者设计了两个结构对齐的分支：
- **先验分支（Prior Branch）**：使用可学习的 $Q$ 作为隐式推理起点，仅依赖当前上下文，是推理时的唯一路径。
- **后验分支（Posterior Branch）**：训练专用，将 $Q$ 替换为未来观测 $\tilde{o}_{0:T}$ 经冻结 ViT 与 Perceiver Resampler 压缩后的嵌入 $z^{\mathrm{post}} \in \mathbb{R}^{K \times d}$。

两个分支共享相同的上下文编码，通过 **dual-branch attention mask** 打包进单一序列完成一次前向传播：共享上下文对两分支可见，但先验与后验的 token 互不交互，确保对齐仅发生在指定的隐式位置。

**训练目标**。总损失包含三项：
1. **Flow Matching 动作损失** $\mathcal{L}_{\mathrm{FM}}$：对两个分支分别计算速度场预测误差。
2. **隐式对齐损失** $\mathcal{L}_{\mathrm{align}}$：对最后 $L=9$ 层 Transformer 中对应隐式位置的隐藏状态 $h_\ell^{\mathrm{prior}}$ 与 $h_\ell^{\mathrm{post}}$ 施加逐点 Frobenius 范数对齐。
3. **反坍缩正则** $\mathcal{L}_{\mathrm{reg}}$：包含模长正则 $\mathcal{R}_{\mathrm{norm}}$（防止 $\|h\|_2$ 低于阈值 $\tau$）与谱多样性正则 $\mathcal{R}_{\mathrm{rank}}$（通过最小化负谱熵防止方向坍缩）。

最终损失为：
$$\mathcal{L} = \mathcal{L}_{\mathrm{FM}} + w_{\mathrm{align}} \mathcal{L}_{\mathrm{align}} + \mathcal{L}_{\mathrm{reg}}, \quad w_{\mathrm{align}}=10^{-3},\; w_{\mathrm{norm}}=w_{\mathrm{rank}}=10^{-4}$$

**推理与部署**。推理时完全移除后验分支，模型仅运行先验分支，不生成任何未来帧。配合 **Universal Async Chunking (UAC)** 异步分块机制，系统级延迟控制在 **3–4 ms/step**，与标准 VLA 相当。

**实验流程**。模型首先在混合人与机器人操作数据的 **UniHand 2.0** 统一格式上进行大规模预训练，随后在六个仿真基准（LIBERO、RoboCasa-50、GR1、LIBERO-plus、RoboTwin 2.0、CALVIN）和三类真实平台（PND Adam-U、Unitree G1、Franka FR3）的 12 项组合式任务上进行微调与评估。

**Python 风格伪代码**：

```python
import torch
import torch.nn as nn

class BeingH07(nn.Module):
    def __init__(self, K=16, d=768, L_align=9):
        super().__init__()
        self.understanding_expert = MoTTransformer()   # Understanding Expert
        self.action_expert = MoTTransformer()          # Action Expert
        self.latent_queries = nn.Parameter(torch.randn(K, d))  # 先验隐式查询
        self.future_encoder = PerceiverResampler()     # 冻结ViT + Resampler
        self.flow_head = FlowMatchingHead()
        self.K = K
        self.L_align = L_align
        self.w_align = 1e-3
        self.w_reg = 1e-4
        self.tau = 0.5  # 模长阈值

    def forward(self, x, o_hist, s, a_gt, o_future=None):
        # 编码共享上下文
        c = encode_context(x, o_hist, s)  # [B, N_ctx, d]
        
        # 先验分支：可学习查询
        q_prior = self.latent_queries.unsqueeze(0).expand(B, -1, -1)
        seq_prior = build_mot_sequence(c, q_prior, a_gt, branch='prior')
        
        if self.training and o_future is not None:
            # 后验分支：未来观测嵌入
            with torch.no_grad():
                z_post = self.future_encoder(o_future)  # [B, K, d]
            seq_post = build_mot_sequence(c, z_post, a_gt, branch='posterior')
            
            # 打包为单一序列，应用 dual-branch attention mask
            seq_packed, attn_mask, pos_ids = pack_dual_branch(seq_prior, seq_post)
            hidden_packed = self.understanding_expert(seq_packed, attn_mask, pos_ids)
            
            # 解包两分支的隐藏状态
            h_prior, h_post = unpack_latent_hidden(hidden_packed, self.L_align)
            
            # 1) Flow Matching 损失（两分支）
            a_t, u_t = sample_flow_path(a_gt)
            v_prior = self.flow_head(a_t, h_prior)
            v_post = self.flow_head(a_t, h_post)
            loss_fm = ((v_prior - u_t)**2).mean() + ((v_post - u_t)**2).mean()
            
            # 2) 隐式空间对齐（最后 L_align 层）
            loss_align = 0.0
            for l in range(self.L_align):
                loss_align += ((h_prior[l] - h_post[l])**2).mean()
            loss_align = loss_align / self.L_align
            
            # 3) 反坍缩正则
            loss_reg = 0.0
            for h in [h_prior, h_post]:
                # 模长正则
                norm = h.norm(dim=-1)
                loss_reg += self.w_reg * (torch.relu(self.tau - norm)**2).mean()
                # 谱多样性正则（负谱熵）
                loss_reg += self.w_reg * spectral_entropy(h)
            
            loss = loss_fm + self.w_align * loss_align + loss_reg
            return loss
        else:
            # 推理：仅先验分支，无未来帧生成
            hidden = self.understanding_expert(seq_prior)
            action = self.flow_head.decode(hidden)
            return action
```

## 第二模块：核心架构解释

本综述的核心“架构”是其**概念分类框架与组织逻辑**，而非单一模型。作者首先建立一个概率统一视角，随后从架构耦合度和功能角色两个维度对文献进行正交拆解。

### 1. 概率统一视角
作者将策略、世界模型与逆动力学模型统一为同一联合分布的不同查询方式：
- **联合分布**：$p(o_{t+1:t+k}, a_{t+1:t+k} \mid o_t, l)$
- **策略模型**：对观测积分，$p(a \mid o, l) = \int p(o, a \mid o_t, l)\, do$
- **被动世界模型**：对动作积分，$p(o \mid o_t, l) = \int p(o, a \mid o_t, l)\, da$
- **可控世界模型**：条件于动作，$p(o \mid o_t, a)$
- **逆动力学模型**：条件于未来观测，$p(a \mid o_{t:t+k})$

这一透镜表明：世界模型与策略并非天然分离的模块，而是同一预测-控制结构的不同因子化。

### 2. 策略耦合的五大架构范式（表 1）
按**预测生成与动作生产的交互方式**分类：

- **IDM-style（逆动力学式）**：解耦的“先预测未来，再解码动作”。世界模型 $\mathcal{W}$ 生成未来观测 $\hat{\mathbf{o}}_{t+1:t+H}$ 或其隐式表征 $\hat{\mathbf{z}}$，再由独立策略头 $\pi$ 映射为动作。代表：UniPi、VPP、TC-IDM。优点是模块化、可解释；缺点是误差累积且预测未必动作一致。
- **Single-backbone（单骨干式）**：观测与动作 token 在统一生成骨干内联合建模，共享去噪/自回归过程。目标为 $\mathcal{L}_{\mathrm{unified}} = \mathbb{E}[\ell(\hat{y}, y)]$，其中 $\mathbf{x}=[z^{v};z^{a}]$。代表：UVA、UWA、Cosmos Policy。优点是可注入大规模视频预训练先验；缺点是推理开销大。
- **MoE/MoT（专家混合式）**：保留视频专家与动作专家的参数分离，通过共享注意力、交叉注意力或交错序列实现深度耦合。代表：Motus、LingBot-VA、DiT4DiT。兼顾模态特异性与信息交互。
- **Unified VLA（统一 VLA 式）**：在 MLLM 骨干内部内化未来预测（未来图像、结构化世界知识或子目标），而非外挂独立世界模型。代表：GR-1、WorldVLA、DreamVLA。
- **Latent-space WM（隐空间式）**：完全避免像素解码，在表示空间预测未来嵌入或条件。代表：FLARE、VLA-JEPA、WoG。计算高效，但损失了显式未来可视化。

### 3. 模拟器双角色框架（第 4 节）
世界模型作为模拟器被划分为两种互补功能：
- **RL 模拟器**：替代真实环境进行策略强化学习。优化目标 $J(\theta) = \mathbb{E}_{\hat{\tau}\sim(\pi_{\theta}, p_{\phi})}[\sum_{t} \gamma^t \hat{r}_t]$，演进路径从静态预训练模拟器（World-Env）到策略-世界模型协同进化（WoVR）。
- **评估器**：在决策时或离线阶段对候选动作/策略进行排名、验证与安全过滤。代表：GPC（在线候选排名）、WorldEval（离线策略评估）。

### 4. 视频世界模型四阶段演进（第 5 节）
- **Imagination-based**：作为想象引擎提供策略监督（Dreamitate、RoboDreamer）
- **Action-controllable**：强调帧级动作条件与因果对齐（IRASim、Ctrl-World）
- **Structure-aware**：引入掩码、几何、多视角等结构先验（TesserAct、RoboVIP）
- **Foundation-scale**：将大规模视频生成基础模型适配为可复用的交互式世界模型（Vid2World、Genie Envisioner、Cosmos Predict）

def world_model_policy_inference(
    obs_t, 
    language_instruction,
    paradigm="single_backbone",  # "idm" | "single_backbone" | "moe" | "latent"
    world_model=None,
    policy_head=None,
    action_candidates=None
):
    """
    基于综述统一概率视角的通用推理框架。
    可实例化为表1中的不同架构范式。
    """
    condition = encode_multimodal(obs_t, language_instruction)
    
    if paradigm == "idm":
        # 解耦范式：显式未来生成 + 逆动力学解码
        future_obs = world_model.sample_future(condition, horizon=H)
        future_repr = feature_extractor(future_obs)  # 对应论文 Φ(·)
        action = policy_head.decode(obs_t, condition, future_repr)
        
    elif paradigm == "single_backbone":
        # 统一范式：联合去噪/生成未来表征与动作
        latent = world_model.init_joint_latent(video_tokens=obs_t, cond=condition)
        for step in range(world_model.num_denoising_steps):
            # 同时去噪视频 token 与动作 token
            latent = world_model.denoise_step(latent, condition, timestep=step)
        action = extract_action_tokens(latent)
        # 可选：显式未来输出用于规划或验证
        future_obs = extract_video_tokens(latent)
        
    elif paradigm == "moe":
        # MoE/MoT 范式：分离专家 + 层间交叉注意力耦合
        h_video = world_model.video_expert(condition)
        h_action = world_model.action_expert(condition)
        for layer in world_model.mixture_layers:
            h_video, h_action = layer.cross_attend(h_video, h_action)
        action = policy_head(h_action)
        
    elif paradigm == "latent":
        # 隐空间范式：无像素解码，直接预测未来嵌入
        future_embedding = world_model.predict_latent_target(obs_t, condition)
        action = policy_head(obs_t, condition, future_embedding)
    
    # 扩展：若用于评估/规划，对候选动作进行推出排名
    if action_candidates is not None:
        scores = [
            world_model.evaluate_rollout(obs_t, cand, condition) 
            for cand in action_candidates
        ]
        action = action_candidates[argmax(scores)]
        
    return action

# 第二模块：核心架构解释

论文提出的 Hamiltonian World Model（HWM）将世界模型重新拆分为四个解耦角色：**感知编码**、**物理演化**、**视觉渲染**、**决策规划**。其数据流如下：

**（1）感知与编码**
编码器 \(E_\theta\) 将历史观察 \(o_{\leq t}\) 映射为结构化的实体级潜在相状态：
\[
z_t = \{(q_t^i, p_t^i)\}_{i=1}^{N}
\]
其中每个实体 \(i\) 对应物体、机器人连杆或动态相关区域，避免使用单一全局向量。

**（2）哈密顿动力学演化**
学习一个标量哈密顿量：
\[
H_\phi(z_t) = \sum_i K_\phi(p_t^i) + \sum_i U_\phi(q_t^i) + \sum_{i<j} V_\phi(q_t^i, q_t^j)
\]
理想保守动力学由哈密顿方程生成：
\[
\dot{z}_t = J\nabla_z H_\phi(z_t), \quad J=\begin{bmatrix}0 & I \\ -I & 0\end{bmatrix}
\]
为适配真实机器人场景，作者将其扩展为**受控-耗散-残差形式**：
\[
\dot{z}_t = (J - R_\psi(z_t))\nabla_z H_\phi(z_t) + G_\psi(z_t)a_t + \epsilon_\psi(z_t,a_t), \quad R_\psi(z_t)\succeq \mathbf{0}
\]
- \(R_\psi(z_t)\) 捕获摩擦、阻尼等耗散效应；
- \(G_\psi(z_t)a_t\) 引入动作控制输入；
- \(\epsilon_\psi(z_t,a_t)\) 负责接触间断、未建模视觉动态等残余现象，并通过 \(\mathcal{L}_{\mathrm{res}}=\|\epsilon\|_2^2\) 约束其幅度，防止模型退化为无结构黑盒。

**（3）视频生成**
解码器 \(D_\theta\) 接收潜在轨迹 \(\hat{z}_{t+1:t+H}\)，生成未来观察：
\[
\hat{o}_{t+1:t+H} \sim D_\theta(\hat{z}_{t+1:t+H})
\]
视觉生成成为底层物理演化的“渲染层”，而非驱动层。

**（4）规划与决策**
对候选动作序列 \(\{a_{t:t+H-1}^{(m)}\}\) 进行 latent/visual rollout，通过效用函数 \(U\) 选择最优动作：
\[
m^* = \arg\max_m U(\hat{z}^{(m)}, \hat{o}^{(m)}), \quad a_t^* = a_t^{m^*}
\]

```python
class HamiltonianWorldModel:
    def __init__(self):
        self.encoder = Encoder()          # E_theta
        self.hamiltonian = HamiltonianNet() # H_phi: K, U, V
        self.dissipation = DissipationNet() # R_psi(z), PSD constraint
        self.control = ControlNet()         # G_psi(z)
        self.residual = ResidualNet()       # epsilon_psi
        self.decoder = Decoder()            # D_theta

    def encode(self, obs_history):
        # obs_history: o_{<=t}
        z = self.encoder(obs_history)
        q, p = split_into_entities(z)  # list of (q_i, p_i)
        return q, p

    def compute_hamiltonian(self, q, p):
        K = sum(self.hamiltonian.kinetic(p_i) for p_i in p)
        U = sum(self.hamiltonian.potential(q_i) for q_i in q)
        V = sum(self.hamiltonian.interaction(q_i, q_j) 
                for i in range(N) for j in range(i+1, N))
        return K + U + V

    def dynamics(self, z, action):
        H = self.compute_hamiltonian(z.q, z.p)
        grad_H = gradient(H, z)           # nabla_z H
        
        J = symplectic_matrix()
        R = self.dissipation(z)           # >= 0
        G = self.control(z)
        eps = self.residual(z, action)
        
        dzdt = (J - R) @ grad_H + G @ action + eps
        return dzdt

    def rollout(self, z_t, actions, dt):
        # actions: [a_t, ..., a_{t+H-1}]
        traj = []
        z = z_t
        for a in actions:
            dzdt = self.dynamics(z, a)
            # 实践中应使用 symplectic integrator；此处为简化示意
            z = z + dt * dzdt
            traj.append(z)
        return stack(traj)  # z_{t+1:t+H}

    def decode(self, latent_traj):
        return self.decoder(latent_traj)  # o_{t+1:t+H}

    def plan(self, z_t, candidate_action_seqs, utility_fn):
        best_score = -float('inf')
        best_action = None
        for a_seq in candidate_action_seqs:
            z_roll = self.rollout(z_t, a_seq, dt=0.1)
            o_roll = self.decode(z_roll)
            score = utility_fn(z_roll, o_roll)
            if score > best_score:
                best_score = score
                best_action = a_seq[0]
        return best_action
```

Q1: 这篇论文试图解决什么核心问题？

A1: 当前世界模型（包括 2D 视频生成、3D 场景重建和 JEPA-like 潜在模型）虽然能合成视觉逼真的未来，但其潜在转移通常是弱结构化的黑盒函数 \(z_{t+1}=f_\theta(z_t,a_t)\)，导致生成的未来缺乏物理有效性、长期 rollout 不稳定、动作因果性弱，且数据效率低下。论文试图解决的核心问题是：**如何让世界模型的潜在动力学具备显式的物理结构，使其预测不仅在视觉上合理，更在物理上可靠、可解释且适用于具身决策。**

Q2: 作者提出的核心解决方案（创新点）是什么？

A2: 作者提出 **Hamiltonian World Models**，其核心创新在于：
- 将潜在状态显式结构化为相空间变量 \(z=[q,p]\)（广义坐标与动量），而非无意义的黑盒向量；
- 用可学习的标量哈密顿量 \(H_\phi\) 通过辛结构 \(J\) 诱导动力学，将转移学习从“拟合向量场”转变为“学习能量景观”；
- 引入**耗散项 \(R_\psi\)**、**控制项 \(G_\psi a_t\)** 和**有界残差项 \(\epsilon_\psi\)**，将理想保守的哈密顿框架扩展为能处理真实世界摩擦、控制输入、接触与非保守力的实用动力学。

Q3: 实验设计的关键支撑（或巧妙之处/数据集特点）是什么？

A3: 该论文是**概念性与框架性论文，未包含任何实证实验、数据集或定量评估**。其论证的关键支撑在于：
- 系统性的理论推导与架构设计，明确分离了“物理演化”与“视觉渲染”；
- 通过与现有三条路线（2D 视频生成、3D 场景中心、JEPA-like）的对比表格（Table 1），清晰界定了各范式的优势与边界；
- 巧妙之处在于将经典哈密顿力学与深度学习的表示学习、生成模型和决策规划进行系统性融合，并坦诚讨论了真实机器人场景中的非理想因素。

Q4: 这篇论文最显著的贡献点（Top 3）是什么？

A4:
[贡献1] 提出了 Hamiltonian World Models 的统一框架，将世界模型的研究重心从“视觉未来合成”重新定位为“物理结构化的潜在动力学建模”，明确了世界模型应为具身智能提供物理原生（physically native）的仿真能力。
[贡献2] 设计了受控-耗散-残差的扩展哈密顿动力学方程，解决了理想哈密顿系统无法直接应用于真实机器人场景（存在摩擦、控制、接触）的关键障碍，为物理归纳偏置的实际落地提供了可扩展的数学形式。
[贡献3] 系统梳理并对比了当前世界模型的三条主流路线（2D 视频生成、3D 场景中心、JEPA-like 潜在模型），以清晰的分类学方式揭示了各路线在物理一致性、动作条件化和长期稳定性上的根本局限。

Q5: 这项工作在哪些相关研究的基础上做了推进？（列举1-2个最核心的前置工作即可）

A5:
[前置工作1] **Hamiltonian Neural Networks (HNNs)** (Greydanus et al., 2019)：该工作首次展示了如何用神经网络从数据中学习保守哈密顿动力学。本文将其从简单的封闭物理系统扩展到具有控制、耗散和残差项的完整世界模型框架，并对接了视频生成与决策规划。
[前置工作2] **Dreamer / Planet 系列** (Hafner et al., 2019, 2020, 2023)：这些工作建立了基于循环潜在动力学的模型强化学习范式，但其潜在转移缺乏物理结构。本文针对其长期漂移和弱动作因果性问题，提出用哈密顿力学作为潜在动力学的归纳偏置进行根本性改造。

Q6: 客观评价：这篇论文的局限性、漏洞或"未讲明的故事"是什么？对后续科研有何启发？

A6: 局限性与未讲明的故事包括：
- **零实证验证**：论文提出了完整的数学框架与架构蓝图，但没有任何实验结果证明该框架在实际机器人任务、标准仿真环境或视频预测基准上优于现有方法；所有关于“数据效率”和“长期稳定性”的论断目前仅为理论假说。
- **表示学习的黑盒性**：作者承认从原始像素中推断出具有真实物理意义的广义坐标 \(q\) 和动量 \(p\) 是“non-trivial”的，但论文并未提供任何具体算法或监督信号来解决这一逆问题；若编码器学出的 \((q,p)\) 只是任意 latent 的重新命名，则整个物理框架将沦为形式主义。
- **非光滑动力学的适配性存疑**：尽管残差项 \(\epsilon_\psi\) 被用来处理接触与碰撞，但真实机器人操作中的接触切换、冲击、可变形物体往往涉及不连续的混合动力学，平滑的哈密顿流假设可能本质上不足以刻画这些现象，论文对此仅做了边界说明而未给出技术路径。

对后续科研的启发：
- 需要开发**端到端的联合训练算法**，同时学习视觉编码器和物理相空间表示，并设计新的正则化或监督机制确保 \(q,p\) 真正对应物理量；
- 必须建立**超越视觉保真度的评估基准**，专门测试世界模型在能量守恒、动量一致性、接触合规性和长期动作因果性上的物理可靠性；
- 应探索**混合动力学扩展**（如事件驱动的接触切换、图神经网络交互模块）与哈密顿骨架的结合，而非仅依赖平滑残差。
